# Enable Lovable Cloud for SalonBook

## Scope
Only one action: turn on Lovable Cloud for this project. No UI, routes, or schema changes.

## What this gives you
- Postgres database with row-level security
- User accounts and login (email/password, Google)
- File storage
- Server-side functions for things like payments, emails, and AI

## Steps
1. Enable the Cloud integration (provisions the backend and wires credentials into the app).
2. Confirm the project builds and the preview still loads unchanged.

## Not included
No tables, auth screens, or booking features yet — those come in a later request.
